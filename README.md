# ДОДЕП

Браузерна 2D-гра: soulslike-рогалик + казино-слот. Сатира на лудоманію: герой у боргу перед підземним казино,
фармить фішки в печерах, «вибиває» босів на слот-машині і намагається погасити борг.

**Стек:** Phaser 3 · TypeScript · Vite · Vitest. Arcade Physics, `pixelArt: true`.

> Статус: **Milestone 1** — каркас, пакування спрайтів, asset manifest, гравець бігає і стрибає по тестовій печері.
> Повний README (алгоритми, GIF, посилання на білд) — у Milestone 8.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юніт-тести (Vitest)
npm run build      # typecheck + статичний білд у dist/
npm run pack       # перепакувати спрайти з assets-src/ (потрібні сирі паки, див. assets-src/README.md)
```

Запаковані атласи вже лежать у `public/assets/`, тому для запуску гри сирі паки не потрібні.

## Керування

| Дія | Клавіатура | Геймпад |
|---|---|---|
| Рух | A/D або ←/→ | лівий стік / D-pad |
| Стрибок (тримати — вище) | Space або Z | A |
| *(M2)* атака / перекат / блок / фляга | J·X / L·Shift·C / K·V / Q·B | X / B / LB / Y |

Дебаг (тестовий рівень): **H** — хітбокси, колізії і стан гравця; **G** — галерея асетів; **1–4** — зброя;
**T** — рівень броні; **R** — на старт. Розкладка — `src/config/input.ts`.

## Структура

```
tools/
  pack-sprites.ts      CLI пакувальника
  pack/                чисті функції: image (crop/scale/rotate/trim), packer (shelf packing), naming
  pack.config.json     які сирі PNG → у які атласи і під якими іменами кадрів
public/assets/         результат пакування (атласи PNG+JSON, фони, index.json)
src/
  config/              ВЕСЬ контент і баланс: маніфест асетів, тайлсети, рух гравця, керування, легенда кімнат
  core/                рушій без прив'язки до контенту
    assets/            типи маніфесту, реєстрація анімацій
    input/             InputMap — дії замість клавіш (клавіатура + геймпад)
    level/             grid (ASCII → сітка), autotile (сітка → що малювати), LevelView, Parallax
    rng.ts             детермінований RNG з seed
  entities/            ManifestSprite (спрайт з маніфесту), Player
  levels/              шаблони рівнів (ASCII)
  scenes/              Boot → Preload → TestCave, AssetGallery
tests/                 Vitest
```

## Як додати новий спрайт (ворога, боса…)

1. Розпакувати пак у `assets-src/<Тека паку>/`.
2. У `tools/pack.config.json` додати аліас у `packs` і джерело в потрібний атлас:
   - `frames` — окремі PNG на кадр (регулярка `match` + шаблон імені з `$1..$9`),
   - `strip` — горизонтальна стрічка кадрів (`frameWidth`, `frameHeight`, `{i}`),
   - `cells` — шматки тайлсету за сіткою.
3. `npm run pack`.
4. Додати запис у `src/config/assets.ts` (атлас, хітбокс, префікси анімацій).
5. Перевірити в галереї (клавіша **G**): видно всі анімації, рамку хітбокса і яких анімацій бракує.
   Відсутні анімації гра замінює fallback-ефектами кодом.

Тест `tests/manifest.test.ts` падає, якщо маніфест посилається на кадри, яких немає в атласах.

## Алгоритми (Milestone 1)

- **Пакування атласу — shelf packing** (`tools/pack/packer.ts`). Кадри сортуються за висотою і кладуться
  зліва направо «полицями»; не влазить по ширині — нова полиця. O(n log n). Прозорі краї кадрів обрізаються
  (trim), а в JSON записується вихідний розмір — Phaser відновлює позицію, анімація не «стрибає».
  Тайлам додається extrude (розтягування крайніх пікселів), щоб не було щілин на дробових координатах камери.
- **Масштабування паку.** «Roguelike Dungeon» уже збільшений у 4 рази; пакувальник зменшує його
  найближчим сусідом (`scale` у конфігу) і перевіряє, що арт справді складається з однотонних блоків (без втрат).
- **Автотайлінг** (`src/core/level/autotile.ts`). Сітка «твердо/порожньо» → кожна тверда клітинка отримує
  тайл заповнення, кожна відкрита сторона — крайовий шматок скелі зі зсувом (нарости вилазять у порожнечу).
  Шари: заповнення → стіни → стеля → підлога. Варіант шматка — хеш `(seed, x, y, роль)`: візерунок
  відтворюваний і не залежить від порядку обходу. Бічні стіни — це верхні шматки, повернуті на ±90° при пакуванні.
- **Затемнення вглиб скелі** — багатоджерельний BFS від усіх порожніх клітинок дає відстань до порожнечі,
  яскравість заповнення береться з таблиці `depthShade`.
- **Відчуття стрибка** (`src/entities/Player.ts`): прискорення/гальмування замість миттєвої швидкості,
  змінна висота (відпустив кнопку — швидкість зрізається), «час койота» (стрибок ще 100 мс після краю),
  буфер стрибка (натиснув за 120 мс до приземлення — спрацює), слабша гравітація на вершині і сильніша при падінні.
  Усі числа — у `src/config/player.ts`.
- **Візуал і колізії розділені**: фізика — невидима тайлмапа 16×16, малюнок — Blitter з атласу.
